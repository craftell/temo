# 0.3.0

Prepared in the self-update feature PR. Not published by this document.

- Add `temo update` for directly installed official release binaries on macOS and Linux.
- Add `temo update --check` to report the latest stable release without writing installation files or opening the TUI.
- Validate release metadata, download SHA-256 checksums, archive contents, and install target before atomic replacement.
- Keep definitions, ownership journals, SSH forwards, and Tailscale routes unchanged.
- Development, Go-installed, and recognized package-managed installations remain managed through their original installation method. Updates target the operating system's resolved executable path.

The release workflow requires the approved tag to match VERSION. After merging, an authorized maintainer can create v0.3.0 on the intended tested commit. This PR does not create that tag or publish assets.

Older binaries lack the update command. Install 0.3.0 once with the existing installer, then use `temo update` for subsequent releases.

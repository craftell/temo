# 0.4.0

Prepared with the route-table feature. This document does not publish a release.

- Show SSH and Serve routes in an aligned table with status, host, and listening/target ports.
- Add a compact header, active-tab styling, status colors, selected-row highlighting, and visible keyboard hints. Labels and selection remain readable without color.
- Keep status and port numbers visible at narrow supported terminal widths. Full route details remain available with Enter or d.
- Default a new SSH route's local port to its target port and keep them linked until the local value is edited. Saved routes retain their values.

Version 0.3.0 is reserved by the separate self-update PR. Merge that PR first, then reconcile this PR against main and published tags before releasing. Include the final version and release notes with this feature, not in a version-only PR. An authorized maintainer can tag the tested merge commit v0.4.0. No tag or release is created by this change.

# Saved entries

## Sub-features

Add and edit named connections. Persist definitions. Filter the list.

## How to get to it (user POV)

Press a. Use e only after the selected backend is confirmed stopped.

## Driving it with tmux

Save using Tab and Ctrl+S. Inspect config.json. Quit and reopen. Search for the name. Edit a stopped entry and verify the row and JSON change.

## Gotchas

A backend status error must block editing. Never use a live config directory.

Live status is UNEXECUTED.
